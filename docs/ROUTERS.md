# Router compatibility

See the complete [router compatibility and driver guide](../controller/ROUTERS.md), also included in the portable controller package. It explains the tested Linksys integration, how to check another brand's actual management capabilities, the command-driver protocol, private configuration and block/restore validation.

A host that runs NetTime is not enough to make every router compatible. The release has an adapter extension point; it does not claim bundled enforcement support for all manufacturers.
